Task 1 - Unification

26. ?- house = house.

Result:
true.

Reason:
The two terms are exactly the same, so unification succeeds.


27. ?- house = abc.

Result:
false.

Reason:
The atoms are different, so they cannot be unified.


28. ?- edge(a,b) = edge(C,b).

Result:
C = a.

Reason:
The structures match, and C takes the value a.


29. ?- edge(a,d) = edge(C,B).

Result:
C = a,
B = d.

Reason:
The variables take the values needed to make both structures identical.


30. ?- edge(C,B) = edge(a,d).

Result:
C = a,
B = d.

Reason:
C matches a and B matches d, so the terms can be unified.


31. ?- edge(A,f(g,h)) = edge(a,B).

Result:
A = a,
B = f(g,h).

Reason:
A matches a, and B matches the term f(g,h).


32. ?- edge(A,A) = edge(b,c).

Result:
false.

Reason:
A would need to be both b and c, which is not possible.


33. ?- edge(A,A) = edge(b,b).

Result:
A = b.

Reason:
Both positions have the same value, so A can be unified with b.


34. ?- A = B, B = f.

Result:
A = B,
B = f.

Reason:
A and B are linked, and B is unified with f.


35. ?- A = B,
       B = f.

Result:
A = B,
B = f.

Reason:
This is the same query written on two lines, so the result is the same.


36. ?- A = B, B = f, A = e.

Result:
false.

Reason:
A becomes linked to f, so it cannot also match the different atom e.
